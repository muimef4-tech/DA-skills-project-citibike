# Data Dictionary — Citi Bike Trips Dataset

## Описание
Словарь данных для датасета поездок сервиса Citi Bike (по результатам выгрузки Pandas).

| Название столбца | Тип данных | Описание / Смысл | Пример значений | Комментарии |
| :--- | :--- | :--- | :--- | :--- |
| `trip_id` | String | Уникальный ID поездки | `LnQzQk`, `IL9boN` | Буквенно-цифровой идентификатор |
| `bike_id` | Integer | Уникальный ID велосипеда | `16013`, `15230` | Идентификатор транспортного средства |
| `weekday` | String | День недели начала поездки | `Mon`, `Thu`, `Wed`, `Sat` | Сокращенное название дня недели |
| `start_hour` | Integer | Час начала поездки (0-23) | `18`, `19`, `11` | Час в 24-часовом формате |
| `start_time` | Datetime | Дата и время начала поездки | `2013-09-09 18:18:55` | Формат: YYYY-MM-DD HH:MM:SS |
| `start_station_id` | Integer | ID станции отправления | `523`, `257` | Числовой ID станции |
| `start_station_name` | String | Название станции отправления | `W 38 St & 8 Ave` | Географическое название / перекресток |
| `start_station_latitude` | Float | Широта станции отправления | `40.75`, `40.72` | Географическая широта (координата) |
| `start_station_longitude`| Float | Долгота станции отправления | `-73.99`, `-74.00` | Географическая долгота (координата) |
| `end_time` | Datetime | Дата и время окончания поездки | `2013-09-09 18:35:28` | Формат: YYYY-MM-DD HH:MM:SS |
| `end_station_id` | Integer | ID станции прибытия | `334`, `236` | Числовой ID станции |
| `end_station_name` | String | Название станции прибытия | `W 20 St & 7 Ave` | Географическое название / перекресток |
| `end_station_latitude` | Float | Широта станции прибытия | `40.74`, `40.73` | Географическая широта (координата) |
| `end_station_longitude` | Float | Долгота станции прибытия | `-74.00`, `-73.99` | Географическая долгота (координата) |
| `trip_duration` | Integer | Длительность поездки в секундах | `993`, `581` | Время поездки в секундах |
| `subscriber` | String | Тип подписки пользователя | `Subscriber`, `Non-Subscriber` | Категория клиента |
| `birth_year` | Float / Integer | Год рождения пользователя | `1968.0`, `1983.0` | Могут быть пропуски (`NaN`) |
| `gender` | Integer | Пол пользователя | `0`, `1`, `2` | 0 = Не указан, 1 = Мужской, 2 = Женский |
